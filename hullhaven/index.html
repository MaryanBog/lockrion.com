Hullhaven

Turn-based tactical space strategy. Hex-grid combat on a 24×24 field, macro-economy with 24 resources, eight unique factions, 57 named shuttles and a map editor up to 216×216.

Request access View screenshots

Core systems

TACTICAL COMBAT

Hex-grid battlefield

24×24 field with cover, five-tier fortifications, turrets, howitzers and drones. 48 combat programs across four protocols: Mechanics, Pyrotechnics, Electronics and Bionics.

SHUTTLE DEVELOPMENT

57 named shuttles

Three classes, each with a unique permanent specialty. Level up to 50, unlock slots, install modules and equip relics.

MACRO-ECONOMY

Settlements and logistics

24 resources, soil bonuses, railway logistics, settlement needs for eight races, and a full production chain from raw ore to advanced composites.

EIGHT FACTIONS

Distinct playstyles

Humans, Synthetics, Arachnids, Crystalloids, Thermids, Amphibians, Mycelids and Symbionts — each with unique units, soil affinity and settlement needs.

CONTRACT SYSTEM

20 random contracts

Plus author-driven scenario chains. Clear conditions, fixed rewards, no hidden timers.

MAP EDITOR

Up to 216×216

Place terrain, rivers, bridges, tunnels, factions, neutral armies and objectives. Export and share.

About the project

Hullhaven is built with Kotlin Multiplatform and Compose Multiplatform. The interface supports English and Russian. The project is approaching its first public version. System requirements and distribution details will be published when the build is ready.
