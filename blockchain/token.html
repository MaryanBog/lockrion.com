Project overview

Lockrion explores a smart-contract model for reserve-backed reward programs on Solana. Each program, called an issuance, defines its reward reserve, participation period, and settlement rules in advance.

The project documentation describes a model in which participant deposits and reward funds are held separately, and rewards follow predefined on-chain calculations.

Design principles

Fixed reward reserve

The documented model defines the total reward reserve in advance and requires full funding before participation begins.

Time-locked participation

Each issuance specifies a participation window and maturity time. Deposit and withdrawal rules are defined by the contract.

Deterministic settlement

Rewards are calculated from predefined rules and on-chain state, using integer-based accounting intended to produce reproducible results.

Separate escrow accounts

The architecture separates participant deposits from the reward reserve and treats each issuance as an independent instance.
